# gopaltenneti.site

Personal portfolio of Gopal Tenneti.

- **Stack:** Vite, Tailwind CSS v4, Three.js (scroll-driven point field), GSAP + ScrollTrigger + SplitText, Lenis smooth scroll.
- **Logos:** brand marks from [Simple Icons](https://simpleicons.org), bundled at build time.
- **Develop:** `npm install`, then `npm run dev`.
- **Build:** `npm run build` outputs static files to `dist/`.
- **Hosting:** Render static site. Build command `npm ci && npm run build`, publish directory `dist`.
